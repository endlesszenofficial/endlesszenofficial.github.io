Privacy Policy

Last updated: 25 November 2026

Endless Zen Uploader is a personal tool used only by the owner of the Endless Zen YouTube channel to manage that channel.

What data it uses

With the owner's permission, it uses the YouTube Data API and YouTube Analytics API to upload and edit the channel's own videos, set thumbnails and playlists, and read the channel's own statistics.

How data is stored

The sign-in token is stored only on the owner's own computer, in Windows Credential Manager. No data is sold, shared with third parties, or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
